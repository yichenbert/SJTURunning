SJTU RUN 路线工作台首次独立发行：**1.0.0**。

包含浅色桌面界面、地图点选与手绘、OpenStreetMap / 高德切换、本地路线库，以及坐标转换和路线采样改进。应用版本与 macOS 包元数据统一为 1.0.0。

下载并解压对应平台的 ZIP。macOS arm64 适用于 Apple Silicon，采用 ad-hoc 签名，未经 Apple 公证。Windows 安装包由 GitHub Actions 构建，附件出现后可下载；未在本机进行 Windows 桌面实测。

43 项本地离线测试通过。未验证真实账号登录、提交、高德在线鉴权或学校成绩认定。
