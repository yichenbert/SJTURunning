# 桌面版 2.3.0

整个界面重新设计为深色侧栏与浅色工作区，保留已有配置及路线。

- 路线与参数：路线轮廓、实际长度、日期、配速和时间集中显示。
- 运行记录：任务进度与日志单独显示。
- 账号设置：登录信息独立填写，不保存密码。
- 路线画布：左侧绘图工具和路线统计，右侧大地图；支持原来的点击、手绘、撤销、导入导出等功能。

地图操作：

- Mac 触控板双指滑动：平移地图。
- 触控板捏合：缩放地图。
- 鼠标滚轮：缩放；右键拖动：平移。
- 部分鼠标只产生角度滚动，累积到一个完整滚轮刻度才缩放，避免小滚动事件导致连续跳级。

性能改动：

- 路线坐标投影和绘图路径缓存，平移只改变画布偏移。
- 平移重绘按约 16 毫秒合并；手绘统计更新间隔约 80 毫秒，笔画结束立即刷新。
- 地图请求移出绘制函数，视野稳定后加载可见图块；优先加载中心并取消离开视野的请求。
- 复用已解码图块，缩放时可显示已浏览过的低一级地图作为过渡。
- 登录过程移到工作线程，网络等待不会阻塞主界面。

基准条件：同机、1050×600 逻辑像素、5000 个合成路线点、180 帧、暖缓存、离屏绘制。基准不发起网络请求，不预下载地图。结果见 `benchmarks/before.json` 和 `benchmarks/after.json`；不能等同于真实桌面帧率或网络加载速度。

Apple Silicon macOS 应用在 dist/SJTURunning.app，压缩包在 release/ 中。使用本地 ad-hoc 签名，未经 Apple 公证。未执行真实账号登录或记录上传。
