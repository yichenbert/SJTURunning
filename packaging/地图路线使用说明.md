# 地图路线版本 1.0.0

双击 `dist/SJTURunning.app`，在“路线与参数”中点击“打开路线画布”。

1. 底图默认定位到交大闵行校区。可右键拖动或双指滑动平移，滚轮或捏合缩放，也可切换到“平移地图”。
2. “点击连线”：沿道路逐点点击，路线按顺序连接；拖动已有节点可调整。
3. “手绘路线”：按住左键沿道路画线；分多笔绘制时，后续笔画会与上一笔的终点连接。
4. 可“撤销”上一次操作、“清空”重新绘制，或“闭合路线”连接终点与起点。
5. 填写路线名称，点击“保存并使用”。程序保存路线，并自动启用“使用自定义路线”。
6. 再次打开或重启程序会恢复路线。取消编辑不会覆盖原路线。
7. “导出路线”保存 WGS84 JSON 路线文件，“导入路线”恢复该文件。

自定义路线按绘制顺序走一遍，距离由路线实际长度决定。原来的固定距离/随机距离输入会禁用，固定或随机配速仍可设置。若需要更长路线，可继续画线或绘制闭合路线；不会自动重复绕圈或改变路线来凑距离。

手绘线不会自动吸附道路，也不会计算导航路线。沿道路转弯处应添加节点或认真描线。保存及导出的坐标为 WGS84，不接受高德/百度坐标文件直接混用。高德画布显示时转换到 GCJ-02，绘图后近似逆转换为 WGS84。默认地图来自 OpenStreetMap；可在画布右上角“高德密钥设置”填写自己的密钥后切换高德。OpenStreetMap 需联网加载当前视野的地图图块；网络失败会显示提示，并可重试。地图加载不会发送账号密码或完整路线，仅请求当前显示区域的图块。按 HTTP 缓存规则保存浏览过的图块，不提供区域预下载。

采样保留路线转弯点、起点和终点，以累计路程分配时间。分段共用边界点，避免距离遗漏。批次使用启动时的配置快照。

本版本仅验证地图绘制、配置持久化和离线数据生成；未进行真实账号登录或上传验证。构建产物为 Apple Silicon / arm64，采用本地 ad-hoc 签名，未经 Apple 公证。

2.5.0 支持在画布顶部下拉框选择“免费地图 · OpenStreetMap”或“高德地图”，旁边显示实际加载状态。主界面和画布都可打开“我的路线”；画布的“保存到路线库”保留多条路线，“保存并使用”同时加入路线库。发送时对自定义路线做坐标转换，避免在运动健康地图上出现整体偏移。
