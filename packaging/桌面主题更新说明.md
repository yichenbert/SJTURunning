# 桌面 UI 外观更新

本次修改 PySide6 桌面应用（`qtui.py`），不是浏览器预览页面。

右上角外观菜单提供「跟随系统」「日间模式」「夜间模式」。默认跟随系统，通过 Qt 的 `colorSchemeChanged` 信号响应系统外观变化；手动选项单独保存在 QSettings，不混入路线配置、账号或地图密钥。

统一主窗口、路线画布、路线库、地图密钥设置、关于及确认弹窗的黑白灰风格；强调色为蓝色。切换主题时同步重新着色已有日志。地图图块保留原色，WGS84 / GCJ-02 转换与原始路线数据不受主题影响。

验证：47 项离线单元与 GUI 测试通过。新增验证包括系统外观通知、手动覆盖、既有弹窗更新、日志重着色、正常文字颜色对比度至少 4.5:1、主题切换前后地图坐标与布局不变及实际点击投影误差小于 0.01 个逻辑像素。系统事件在测试中模拟；未改动 macOS 全局外观设置。主界面及路线画布的两套主题均已渲染检查。

构建产物：`dist/SJTURunPlus.app`。更新本机 `/Applications/SJTURunPlus.app` 时，旧版本备份到 `release/backups/SJTURunPlus-before-desktop-theme-20261014.app`；更新后校验签名与构建产物逐文件 SHA-256 一致。
