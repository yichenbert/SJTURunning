# macOS 构建说明

源码来源：https://github.com/Gnonymous/SJTURunning

构建基础：提交 9938d0d58569eaa3a9c3ede8bb85780bf73140de，上游版本 2.1.1；当前 SJTURunPlus 版本 1.2.0（整合此前本地 2.5.0 的功能）。

本机产物面向 Apple Silicon（arm64），入口为 `dist/SJTURunPlus.app`。
双击即可打开，无需单独安装 Python。为兼容旧版，配置仍写入
`~/Library/Application Support/SJTURunning/config.json`。

使用 Python 3.11 创建 `.venv`，从 `packaging/requirements-macos.lock.txt`
安装依赖后，执行 `packaging/build-macos.sh` 可重新构建。
源码运行方式：`.venv/bin/python qtui.py`。

本地版本加入地图手绘路线及路线采样，修复分段边界距离遗漏。2.3.0 重写主界面和地图编辑器，增加路线绘制缓存、图块调度和触控板平移支持。使用方法见同目录“地图路线使用说明.md”。窗口启动与离线测试不代表真实登录、上传或有效成绩验证。

2.4.0 增加高德官方 JS API 2.0 接入及独立浅色确认弹窗。内嵌 Qt WebEngine 已随应用打包，安装包体积比 2.3.0 增大。高德密钥不随应用提供，请按“高德地图接入说明.md”配置。

2.5.0 加入画布顶部地图切换、加载状态和本地路线库；修复地图路线发送时遗漏 WGS84 → GCJ-02 转换的问题。使用说明见“坐标修正与路线库说明.md”。
