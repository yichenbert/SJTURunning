# SJTURunPlus 图标处理

原图为 1536 × 1024（3:2），原文件未修改。

使用内置 imagegen 编辑工具重新调整为方形构图，再以平滑圆角轮廓封装图标。最终 PNG 为 1024 × 1024 RGBA，圆角外侧透明；同步导出 macOS ICNS、Windows ICO 和 Web PNG。

编辑要求：保留金发人物、棕色眼睛、眨眼表情、抬手姿势、白蓝水手服、水彩纸纹理及星星装饰；调整为 1:1 方形构图，突出面部，移除原矩形黑框；使用 macOS 风格圆角方形和透明外边距，不添加文字、人物或立体光泽。第二轮仅清理透明轮廓外的杂点，保留内部构图。

最终资源：`assets/SJTURunPlus.png`、`assets/SJTURunPlus.icns`、`assets/SJTURunPlus.ico`。
