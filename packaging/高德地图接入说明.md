# 高德地图与界面更新 · 2.5.0

## 启用高德

1. 打开应用 → 打开路线画布 → 右上角“高德密钥设置”。
2. 在高德开放平台创建应用，申请 **Web 端（JS API）** Key 及对应的 **securityJsCode**，不是 Web 服务 API Key。
3. 将两项分别填写到设置页，将地图来源切换为“高德地图”，然后保存。如设置域名白名单，请允许 `localhost`。
4. 等待地图加载。成功时右上角显示“高德 · 已启用”，底部显示“高德地图已加载”。错误时检查平台类型、密钥配对、域名和网络，然后点击“重试地图”。

[高德官方准备说明](https://lbs.amap.com/api/javascript-api-v2/prerequisites) · [安全密钥说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)

没有密钥时，继续显示 OpenStreetMap；不会把现有底图标成高德，也不会使用未经文档公开的图块接口。

## 路线与坐标

高德官方使用 GCJ-02；现有路线和 JSON 文件使用 WGS84。程序在高德画布显示时转换，绘制后近似逆转换为 WGS84。仅切换地图不会重写已有路线。转换测试覆盖参考坐标和校园坐标往返，但不是实地测绘精度认证。

[高德官方坐标说明](https://lbs.amap.com/api/javascript-api-v2/guide/transform/convertfrom)

已定位并修复地图路线发送前遗漏坐标转换的问题，依据运动健康公开前端直接使用高德绘制轨迹。已有地图路线仍保存为 WGS84，发送时转换为 GCJ-02；免费地图和高德地图均使用同一发送流程。真实高德鉴权和修复后的手机端位置尚未通过新记录验证：当前配置仍缺少安全密钥，本次未执行上传。

支持点击连线、手绘、平移、节点拖动、撤销、闭合、导入导出。自由手绘时地图不跟随鼠标平移；要浏览区域请切换“平移地图”。节点较多时只显示部分编辑手柄。

## 密钥保存

地图设置单独保存在应用配置目录下的 `map-settings.json`，macOS 文件权限为 0600，不写入路线导出文件，不传给跑步上传接口。JS API 密钥会交给高德官方脚本使用；浏览器中的 JS 安全密钥不等于不可提取的服务端秘密。

## 界面

确认提交改为浅色卡片，分栏展示账号、日期、路线配速和时间；按钮为“返回修改”和“确认并开始”。Esc 返回修改，默认不自动确认。提醒弹窗和地图设置也固定使用浅色配色，避免系统深色模式导致文字不可读。
