# 坐标修正、地图切换与路线库 · 2.5.0

## 坐标问题

免费地图及程序保存的路线使用 WGS84，高德地图使用 GCJ-02。旧版在高德编辑器内做了显示转换，但提交地图路线时没有转换，导致运动健康以高德坐标解释原始 GPS 坐标。用户当前路线起点的两种坐标相差约 490 米。

本次核对了[运动健康公开前端](https://pe.sjtu.edu.cn/phone/)：轨迹详情把 `tracks[].points` 的经纬度字符串直接用于高德曲线。高德官方的[坐标说明](https://lbs.amap.com/api/javascript-api-v2/guide/transform/convertfrom)说明高德使用 GCJ-02。

现在在 API 边界统一转换地图路线的 `latLng` 和 `location`，规则查询起点也采用相同坐标系。程序内路线、路线库和导出文件继续使用 WGS84；距离、时长和采样不因显示转换改变。原始数据不被改写，每次提交从原始采样复制转换；切换地图不会重复转换。未启用自定义路线的旧接口保持原坐标行为。

已用离线测试验证发送坐标反转换后回到原路线，并核对坐标字段一致性。没有执行新的真实上传，所以尚未验证手机端最终显示或成绩认定；已有错误位置的历史记录不会自动修改。

## 地图切换

画布顶部下拉框提供“免费地图 · OpenStreetMap”和“高德地图”。旁边状态标记会显示“加载中”“已启用”或“加载异常”。高德未配置完整时，切换会提示填写 JS API Key 和 securityJsCode；取消后继续免费地图。密钥在“高德密钥设置”填写。当前本机保存了 Key，但 securityJsCode 为空，因此仍使用免费地图。

加载异常不会显示“已启用”，可重试或切换回免费地图。切换时保留路线点、名称及撤销历史。

## 保存与再次调用

- 画布“保存到路线库”：保存当前名称和路线，继续编辑。
- 画布“保存并使用”：加入路线库并设为当前路线。
- 主界面或画布“我的路线”：选中路线可预览长度、节点和轮廓，点击“使用这条路线”或双击列表项调用。
- 路线库支持重命名和导入已有 WGS84 JSON 文件。相同名称和相同点的重复保存不添加副本；同名但不同路线自动加编号，保留旧路线。
- 路线库保存在应用配置目录的 `routes.json`，重启后仍保留。首次启动自动收录旧配置中的当前路线。
- 保存前读取高德浏览器中的最新笔画，避免异步通信导致末笔丢失。
